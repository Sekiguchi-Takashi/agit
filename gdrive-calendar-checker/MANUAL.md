# Google Drive / Calendar 連携チェッカー 利用マニュアル

スマホのブラウザだけで、**Google DriveとGoogle CalendarのAPIキー（アクセストークン）が正常にHTMLから連携できるか**を確認するツールです。

- Google Drive: 接続確認後、**フォルダ数**を表示します
- Google Calendar: 接続確認後、**本日の予定の件数**を表示します
- 結果は **1つのチェックファイル**（Drive・Calendarの結果をまとめたテキストファイル）として保存します

対象ファイル: `index.html`（このファイルと同じフォルダにあります）

---

## 1. 事前準備：アクセストークンの取得

Google Drive・Google Calendarは個人のデータ（ファイル一覧・予定）にアクセスするため、`api-checker`のGemini/Mapsキーのような単純なAPIキーではなく、**OAuth2アクセストークン**が必要です。動作確認用に、以下の手順でその場で取得できます。

1. スマホのブラウザで [Google OAuth 2.0 Playground](https://developers.google.com/oauthplayground) を開く
2. 右側の「Select & authorize APIs」で、確認したいAPIのスコープにチェックを入れる
   - Google Drive用: `https://www.googleapis.com/auth/drive.readonly`
   - Google Calendar用: `https://www.googleapis.com/auth/calendar.readonly`
   - 両方確認したい場合は両方チェックしてから進めてOK（1個のトークンで両方使えます）
3. 「Authorize APIs」→ 自分のGoogleアカウントでログイン・許可する
4. 「Exchange authorization code for tokens」を押すと **Access token** が発行されるのでコピーする

> 注意: アクセストークンは通常1時間程度で失効します。失効した場合は同じ手順で再取得してください。
> この方法はその場の動作確認用です。自分のアプリに組み込む場合は、別途Google Cloud ProjectでOAuthクライアントを作成し、正式な認可フローを実装してください。

---

## 2. ファイルをスマホで開く方法

1. `index.html` をスマホの内部ストレージにコピーする（PCからの転送、またはブラウザでのダウンロード）
2. スマホの「ファイル」アプリで `index.html` を開き、「Chromeで開く」など、ブラウザで開くことを選択する

GitHub Pagesなどで公開している場合は、そのURLを直接開いても構いません。

---

## 3. 使い方

1. 「Google Drive」欄に1章で取得したアクセストークンを貼り付ける
2. 「Google Calendar」欄にも同じ（または別の）アクセストークンを貼り付ける
   - どちらか一方だけ確認したい場合は、もう片方は空欄のままでOK（「トークンが未入力のためスキップしました」と表示されます）
3. 「テスト実行」をタップする
4. 結果が表示されます
   - **Google Drive**: 接続結果（OK/NG）と「フォルダ数: N件」が表示されます。フォルダ数はゴミ箱に入っていないフォルダの総数です
   - **Google Calendar**: 接続結果（OK/NG）と「本日の予定の件数: N件」が表示されます。スマホの現在の日付・タイムゾーンを基準に「今日」を判定します
5. 「チェックファイルを保存」をタップすると、Drive・Calendar両方の結果を1つにまとめたテキストファイルがダウンロードされます

---

## 4. チェックファイルの保存方法（内部ストレージ／Documentsフォルダ）

「チェックファイルを保存」を押すと、`check_drive_calendar_YYYYMMDD_HHMMSS.txt` という名前で**Drive・Calendarの結果を1ファイルにまとめて**ダウンロードされます。

ブラウザの仕様上、JavaScriptから保存先フォルダを直接指定することはできません。**内部ストレージの「Documents」フォルダに保存したい場合は、以下を設定しておくと保存時にフォルダを選べます。**

### Android + Chromeの場合

1. Chromeの「⋮」→「設定」→「ダウンロード」を開く
2. 「ダウンロード前に保存先を確認する」を **ON** にする
3. 「チェックファイルを保存」をタップすると保存先選択ダイアログが出るので、`内部ストレージ` → `Documents` フォルダを選んで保存する

設定していない場合は既定の `Download` フォルダに保存されるので、その場合は「ファイル」アプリで `Documents` フォルダへ移動してください。

## 6. トラブルシューティング

| 症状 | 主な原因 | 対処 |
|---|---|---|
| HTTP 401 | アクセストークンが無効・期限切れ | OAuth Playgroundで再取得する |
| HTTP 403 | 必要なスコープが付与されていない、APIが有効化されていない | 1章のスコープを再確認、Google Cloud ConsoleでDrive/Calendar APIが有効か確認 |
| フォルダ数が0件 | フォルダが実際に無い、共有ドライブ上のフォルダは集計対象外 | マイドライブ上にフォルダを作成して再テスト |
| 本日の予定の件数が想定と違う | スマホの日付・タイムゾーン設定がずれている、終日予定の扱いの違い | スマホの日付・タイムゾーン設定を確認 |
| 通信エラー | 通信環境、まれにCORS制限 | Wi-Fi/モバイルデータの状態を確認して再試行 |

---

## 7. セキュリティ上の注意

- アクセストークンは第三者に渡さないでください。チェックファイルにはトークンの一部のみ（先頭4文字・末尾4文字）を記録しますが、それでも他人に共有しないことを推奨します
- トークンをGitなどのリポジトリにコミットしないでください
- 不要になったトークンは、[Googleアカウントのセキュリティ設定](https://myaccount.google.com/permissions)からアプリの連携を解除できます
